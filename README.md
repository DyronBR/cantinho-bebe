# Cantinho do Bebê - E-commerce

Plataforma de e-commerce para produtos de bebês desenvolvida com **Next.js**, **React**, **TypeScript** e **TailwindCSS**.

## 🎯 Funcionalidades

- ✅ Página de produtos com 3 visualizações (Grid, Compacto, Lista)
- ✅ Modal de detalhes de produtos com especificações
- ✅ Filtro por categoria e busca em tempo real
- ✅ Design premium e responsivo
- ✅ Header e Footer integrados
- ✅ Produtos similares recomendados

## 🛠️ Tech Stack

- **Frontend:** React 18, Next.js 16, TypeScript
- **Styling:** TailwindCSS, Shadcn/ui
- **State Management:** React Hooks (useState, useEffect)
- **Responsividade:** Mobile-first design

## 📦 Instalação
```bash
# Clonar repositório
git clone https://github.com/DyronBR/cantinho-bebe.git
cd cantinho-bebe

# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build para produção
npm run build
npm start
